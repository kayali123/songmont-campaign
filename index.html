一页纸 · 战役总纲

一句话：Songmont 眼下的死结不是不够美，而是「没人认识」加「配不上价」两个心结叠在一起，又被舆论点名「重营销轻设计」。「见针」把答案收进一个动作：每年只讲一位真实的手作人和她手里的一道工序，把包上那道看不见的针脚，变成一个有名字、有脸、可溯源的人。讲得越多，越是在讲这只包到底怎么做出来的。这是对「重营销轻设计」最结构性的回击。
  1. 母题是「针脚」，护城河是「这群有名字的人」。 品牌自己的风、山、野、生长已经用得很密，月相被松月占了、云山被老花占了。针脚是包上真实存在、却从没被讲透的东方切口，是入口和视觉母题；但真正抄不走的不是针脚（谁都能讲手作），是里望村这群有名有姓的姥姥、和付家三代这条真实纵线，只有 Songmont 有。
  2. 一个母题贯穿两个死结。 认知靠巴黎 + 小红书 + PR 在漏斗上层做广谱触达，信任靠「见针保修 + 验真 + 档案」在漏斗下层把已被吸引的人推过购买犹豫、并留住复购。同一个针脚母题贯穿始终、各触点分工明确，这才是品牌营销岗要看的杠杆思维。
  3. 不押任何外部资源。 主角是品牌已有的万荣姥姥手作团和付家三代女性，故事自我供给三年。澄泥砚、代言是加分嫁接，不是命门。
  4. 巴黎立势，双 11 收口。「远山有声」是 Songmont 已跑通两年的国际展览舞台，「见针·万荣」是今年这台展的剧目：默认让姥姥在里望村实拍、巴黎现场以影像与作品呈现（真人到场为条件成熟时的升级项），把「手作被世界看见」推到最高潮；双 11 用信任内容叠加电商常规机制承接转化，稳住天猫箱包榜位置。

一、背景与挑战

1. 品牌处境：登了顶，但被追，也被质疑

行业研究已经判定：中国原创设计师包袋处在成长期偏早中段，价值在软端（设计、叙事、DTC 内容），Songmont 已经在 2025 双 11 登上天猫双 11 箱包榜第一、反超 Coach 品牌公开口径。但两件事同时在发生。一是 Coach 逆势复苏，大中华区强劲增长、计划三年开约 100 店，中端需求是被争夺而不是被本土单边吃下。二是 2026 年初品牌被媒体点名「设计趋同、高价低质、假货泛滥、重营销轻设计」，这不是可以回避的噪音，而是这份提案必须正面回应的题目。

真正的挑战不是声量不够，是信任不够。一个已经登顶的品牌，继续砸声量的边际收益在递减，而「重营销轻设计」的质疑恰恰会被越高调的营销放大。这份提案的任务，是把营销从「制造声量」转向「兑现信任」，让每一次传播都在替产品说话。

2. 两个心结，其实同源

回到顾客那一端，中女买 Songmont 时反复出现两句话。一句是「没有必要花几千元买一个大家都不认识的包」，这是认知锚点缺失。另一句是「花三四千买它，就像花奢侈品的钱买快时尚」，这是信任缺失。表面是两个问题，根子是同一个：这只包背后到底站着谁、值不值，用户看不见。

把死结说清楚：认知问题问的是「你是谁」，信任问题问的是「你配吗」。只要让用户看见包背后那个真实的人和那道真实的工序，两个问题一起松开。答案不在讲一个更玄的东方美学，而在把人推到台前。

二、洞察

1. 人群：要的是被看见，不是被定义

核心人群是一二线 28 到 40 岁的高知中产女性，律师、策展人、花艺师、旅行博主。她们对大牌 logo 祛魅，为「自我价值导向、听从内心」买单。顾客原声里最稳定的三条情绪母题是：松弛不被定义、内核稳定的力量、自我和解与治愈。她们不是炫富人群，是内核稳定人群。购买触发很理性，能装、有调性、保值百搭；最大的顾虑就是前面那两个心结。

顾客原声取样（供文案定调，非逐字硬引）：看代言短片「有种被温柔的女性友人拥抱了一下」；加购纠结「反复加购是因为反复被打动，删除是因为价格」；品质差评「售价三千的包，不到半个月开线掉皮」。这几句同时给出了情感开关和信任缺口。

2. 母题占位审计：为什么必须绕开「风」和「山」

要做一个能连载三年的东方母题，先得确认这块地没被占。我们对品牌自有母题和同行做了一次占位审计，结论很清楚：Songmont 自己已经把风、山、野、成风、生长用得很密，月相被「松月」占了，云山青松被老花系列占了，同行也都在抢自然意象。再用一次风山，就是自我重复加同质化。

两个层次要分清：「风 / 山」在产品叙事母题层已被用旧、慎用；但在展览 IP 外壳层，「远山有声」是品牌已有的国际认知资产、可继续做舞台品牌（见第六、七章）。见针绕开的是前者，复用的是后者，不矛盾。

把这份审计放进洞察层，本身就是回应 JD「基于品牌定位开展市场洞察与竞争研究」的证据：创意不是拍脑袋，是先算清楚哪块地能长东西。

3. 品牌真相：一条抄不走的祖孙三代女性纵线

Songmont 手里有一条别的包袋品牌讲不了的真相。2013 年，创始人付崧（清华美院出身、曾在谷歌做设计）因为买不到理想的电脑包，让擅长缝纫的母亲付玉兰缝出了第一只祖母绿托特；创始人的姥姥一辈子做当地非遗虎头帽；2015 年，品牌在山西万荣里望村组建了一支平均年龄六旬的姥姥手作团队。品牌公开口径 从山西乡村一双手，到 2024、2025 连续两年登上巴黎时装周，这条纵线同时装下了文化自信、新中式和中女悦己三重共鸣。

洞察落点：这条纵线的主角不止姥姥，而是买家与手作人两端：当买包的年轻女性和缝包的年长女性在同一道针脚上相遇，买家不是围观一场传承，而是「我背的这只包让这双手被看见，也让我被这双手认真对待过」。「被看见」于是从品牌口号，变成两代女性互相成全的事实。

三、大主意「见针」

◆见针 · 一针，一个人
大主意

每一年，Songmont 只讲一位真实手作人和她手里的一道工序，把包上那道看不见的针脚，变成一个有名字、有脸、可溯源的人。见物，也见人。

母题

用「针脚 / 手作的时间与温度」替代已被用旧的风与山。针脚是手作的签名，是时间的计量单位（品牌称开发周期 180 到 300 天 品牌称在这里不是营销数字，是一针一针熬出来的），是使用痕迹与陪伴的起点。

情感主线

A 文化叙事，落点是「两代女性互相成全」：不是让买家围观姥姥被看见，而是双主角同框——买家的手与使用痕迹，和姥姥的针脚在同一只包上相认。你让这双手被看见，这双手也认真对待过你。买家是显性受益者，不是旁观者。

信任底座

C 工艺信任：不是在包外面贴叙事，而是把设计和工艺本身推到台前当主角（详见第四章「见针保修」）。

Slogan

主句：一针一个名字，把手交给时间。　辅句：见物，也见人。

为什么这是从品牌价值出发，而不是蹭热点

  • 护城河是真人，不是母题。 针脚、手作是谁都能讲的通用母题；真正抄不走的是付家三代、里望村这群有名有姓的姥姥——她们是 Songmont 独占的真人资产，不依赖任何外部热点或生肖流量，就能自我供给多年内容。
  • 它兑现的是品牌的美学内核和调性。 「自然、自知」，谦卑、克制、陪伴、平视，不做 logo 炫耀。见针把这套内核变成可看可核的动作，而不是形容词。
  • 热点会过，针脚会留。 「把手交给时间」是可连载、越讲越厚的品牌资产，跟追一次流量截然相反。

与「重营销轻设计」正面对撞：这个质疑的要害是「你的营销是不是空的、产品撑不撑得起」。见针的母题就是产品本身那道针脚，信任层就是缝它的那双手来重缝。你讲得越多，越是在讲产品怎么做出来的。这是其他方向做不到的结构性回击。

四、信任层 · 见针保修

这一章是整份提案的胜负手。信任层不是口号，是三个品牌可自主兑现的动作（一针一档案、见针保修、验真溯源）加一个可选的外部增强项（澄泥砚，签下才启用）。直接回应品控、假货、涨价三类真实质疑。落地方式是试点先行：先在一个城市、一款限量跑通售后养护的 SOP 与成本模型，跑通单位经济再决定放量，避免「承诺大于兑现」的翻车路径。

01一针一档案：把针脚变成可核验的人
做什么

限于每只当年 IP 限量款（先把规模压到可控）：附一张手作人卡片，姓名、里望村、这道工序做了多少年、耗时多少针；扫码进「见针档案库」看她本人缝制的原始视频；五金与皮料以第三方检测报告加工序纪录片透明公开，不做参数轰炸。

怎么落

拆成两件事分别定责：内容侧（肖像与工序视频）走内容团队常态产能；溯源侧（唯一码 + 检测报告上架）是 IT + 品控 + 法务的系统工程，作为「信任基础设施」单列，不混进营销 campaign 预算（见第九章分界表）。

解什么

同时补认知锚点（这只包背后是谁）和信任缺口（它到底怎么做的）。

02见针保修：分层履约，把售后变成关系
做什么

针对掉色、开线、掉皮、五金四类真实高频顾虑，给出免费养护与重缝承诺。分层履约：当年 IP 限量款（量小可控）由姥姥团亲手重缝，其余存量走「里望村工坊监制的专属维修中心」重缝——话术归到手艺传承，不把返修压在某位姥姥的新品工时上。先一城一款试点跑通再放量。

算过账

返修不是无底洞：以试点数据估算保修率、单次返修工时与成本，给它设一个占营销盘的上限（演示假设，落地按内部数据重定），跑通单位经济再全国放量。且它多为供应链履约成本、不是营销花费（见第九章分界表）。

解什么

把已被吸引的人推过购买犹豫、并留住复购：购买即进入一段「被那双手长期照顾」的关系。这是本案在漏斗下层的核心杠杆。

03验真溯源：每只包唯一编号，一键辨真伪
做什么

唯一编号绑定手作人与检测批次，官方一键验真。把「假货泛滥」的舆论危机，转成「教你辨真伪 + 正品服务」的信任内容。

04澄泥砚做慢工的第三方物证 策略假设 · 拟合作
做什么

嫁接绛州澄泥砚这项山西非遗：河泥沉淀一到两年才成器，泥比石更坚。把品牌自说自话的「慢」，换成一个有非遗背书、物理上同构于「植鞣皮越养越润」的可触证据，替品牌的时间做一个不自说自话的旁证。

口径

此项及后文所有非遗合作均为 策略假设，需真签约、真联名、真出镜方可对外，绝不以贴图借势替代。

一条纪律贯穿信任层：不为涨价背书。工艺透明是为了让人看懂价值，不是为溢价找借口。任何调价都逐项拆成可见成本，绝不复制「情怀绑架」话术。

五、三年 IP 弧线

母题固定：每年一位手作人，加一道工序，加一张可溯源档案。内容逐年长大，IP 具备继续连载多年的骨架。

第 1 年见其手

立母题。主线人物锁定创始原点、也是授权关系最清晰的一位：母亲付玉兰（品牌零号员工）缝的第一只祖母绿托特，加姥姥的非遗虎头帽针法。档案库先上轻量版（手工维护一批手作人卡片，系统化溯源留到跑通后再上），保修只做一城一款试点。第 1 年本身就是一个能独立成立、可收口的完整战役，把认知锚点从 0 做到 1；第 2、3 年是复利加分，不是凑齐三部曲才成立。

第 2 年见其名

从付家三代扩到万荣姥姥团整体，每季认识一位姥姥。主打「她们本来无名，现在包上有她们的名字」，把 UGC 引向「我背的这只是谁缝的」。

第 3 年见其传

姥姥带出的年轻学徒、非遗针法的当代化，甚至邀请用户参与一道可选手工工序（如亲手绑一个虎头帽挂饰）。从看见手作，到参与手作。

一年一主线人物，一支群像做底盘：主线人物只负责声量峰值和 PR 记忆点那两三个月，618、七夕、日常店播等大量节点用可复用的工序、使用场景、UGC 群像内容托底。这样既保证主线不被日常带货稀释，也回答了「一年只讲一个人够不够填满一整年」。

稀缺性来自「这位姥姥今年只做这么多针」，真实而非人造饥饿。双 11 落地页嵌档案库与验真溯源，正面回应价格质疑。要说清一点：信任内容是叠加项而非替代项——守住榜位仍需与电商团队的常规大促机制（满减、权益、店播）配合，信任内容负责的是「不打价格战地维持客单与心智」。

七、整合渠道打法

打法总纲：不是多渠道铺量，而是「小红书种草飞轮为主阵地，买手 / 店播做成交，线下策展造声量峰值，抖音做破圈，播客与 PR 做深度与背书」的组合。全链路一句话：巴黎立势，小红书养草，抖音播客扩声，双 11 收口。依据是品牌自有数据，内容质量比投放预算更能起量。

1. 小红书：绝对主场，见针档案库做内容中台

  • 人群反漏斗 + AIPS 分层，先卡「28 到 40 中女、悦己、通勤、新中式」核心人群再外扩。品牌现有 67.1% 声量在小红书 品牌公开口径。
  • 达人金字塔：3 到 5 位垂类头部背书，加数十位腰部场景实测，加大批 KOC 铺真实感。
  • 搜索卡位单列：搜索转化显著高于推荐 第三方口径，建品牌词、品类词、长尾词库，狙击「平替」竞品词。
  • 内容中台：以「见针档案库」为选题源，产出手作人肖像故事、工序慢直播、「猜猜这只是谁缝的」互动、「我的包背后的姥姥」UGC 征集。

2. 线下：策展式限时展，巴黎峰值 + 国内巡展前置

「远山有声」是舞台，「见针·万荣」是今年的剧目：复用品牌已跑通两年的国际展览外壳（远山有声、风生·造物），不必从零搭展。巴黎做年度峰值，国内一线城市巡回小展做转化前置。也要诚实说，即便复用基底，把姥姥影像、手作装置与海外公关搬进巴黎章仍是一笔不小的增量成本（已在第九章单独立项），不是零成本复用。每场展都是「可拍照加有文化叙事」的素材源，前置 KOC 分发反哺飞轮。

3. 抖音 · 播客 · PR

  • 抖音：承接情感短纪录片破圈，把小红书爆款单品叙事在兴趣电商重做。抖音声量占比低但互动贡献高 品牌公开口径，适合大事件撬互动。
  • 播客《山下声》：走「被看见的女性 / 手作与时间」深度对谈，触达高知女性。
  • PR：主打「手作被世界看见」文化叙事稿（默认走姥姥影像，真人到场则升级为「姥姥登巴黎」）；信任状矩阵（连续两年巴黎时装周、创始人入选 2025 BoF 500）系统化成海外社媒资产。

4. 代言假设 策略假设

选角逻辑锁定气质派、影后路线（如吴彦姝这类年龄气质与姥姥团呼应者），在巴黎现场做「两代女性对话」共创，而非顶流带货。依据是品牌已验证 PGC 少量声量撬动多数互动、代言走气质派而非流量的路径 品牌公开口径。此为策略假设，落地需实际签约。

协同的关键前提写在明处：信任层承诺一旦对外，就必须真兑现。供应链品控要先过关，任何一次翻车都会因为高调透明而被放大。所以本案把供应链定为「前置」团队，而非事后配合。

把我的边界说在明处：见针的胜负手落在供应链、客服、IT、法务，这些不归品牌营销出预算、也不由我一个人拍板。我在这里的职责，是把已有的工艺与售后能力翻译成可传播的信任资产，而不是替供应链承诺产能。具体依赖：保修 SOP 由售后主导、营销负责内容化；验真系统若公司已有防伪能力则复用、没有则本案不强上；外观设计专利为建议项、非本 campaign 交付物。承认边界，才谈得上落地。

九、预算与 ROI

一份讲 ROI 的方案，不能只有 R（结果）没有 I（投入）。本章把「千万级」这个 10 倍跨度的模糊说法收成一个可辩护的演示盘，并做一件全篇最要紧的诚实动作：把最烧钱、又最不受营销控制的信任层履约，从营销预算里切出去。

1. 口径与量级

用前置行研自己的数反推（Songmont 2024 仅包袋近 5 亿、2025 线上 +90%，全渠道估 7–9 亿；品牌端营销费按收入保守 12–18% 计），品牌年度营销盘的现实量级是亿级。所以本案把口径写清楚，不再用模糊的「千万级」：

见针 IP 首年整合营销盘 ≈ 4000–6000 万（中枢约 5000 万） 演示口径，是年度亿级营销盘里投给见针这一个旗舰 IP 的部分，不是公司全部营销费用。常态年（第 2–3 年）中台已建成、试点已跑通，边际降到约 2500–4000 万。所有金额为演示区间，落地以品牌内部实际预算重校。

信任层的动作不能全算成营销花费，否则会虚高营销 ROI、也误导评审。营销盘只买「把信任讲出去」，不买「履约本体」：

5. ROI 双口径

  • 转化口径：双 11 给目标 ROAS 与「种草到成交（小红星归因）」区间 演示假设，进公司按内部基线重定。
  • 蓄客口径：开档数、养护权益领取、续圈复购，用 CAC 与 LTV 视角衡量长期关系，而非只看当期 GMV。
  • 品牌资产口径：巴黎峰值明确走搜索指数 / 媒体曝光当量，不拿峰值声量硬算直接转化。

所有金额与目标均为演示区间、非承诺。预算的价值不在数字大小，在配比逻辑与营销 / 履约的清晰分界——这两点才是评审要看的「你会不会花钱、分不分得清账」。
